🎯 راه‌اندازی — قدم به قدم

روی هر مرحله کلیک کن تا باز بشه.

۱ ساخت حساب Cloudflare (رایگان) ۲ دقیقه
  1. برو به dash.cloudflare.com/sign-up
  2. ایمیلت رو وارد کن (همون جیمیلی که برای Apps Script استفاده می‌کنی)
  3. یه رمز قوی بساز (حداقل ۸ کاراکتر)
  4. روی Create Account بزن
  5. ایمیل تأیید رو در اینباکس جیمیلت چک کن
  6. روی لینک تأیید کلیک کن
💡 نکته برای کاربر ایرانی: اگه با IP ایران باز نمی‌شه، یه پروکسی ساده وصل کن. بعد از ثبت‌نام دیگه نیازی نیست.
۲ ساخت API Token ۳ دقیقه
  1. برو به صفحه API Tokens
  2. روی Create Token کلیک کن
  3. پایین صفحه، "Edit Cloudflare Workers" پیدا کن
  4. روی Use template کنارش بزن
  5. نام بذار: Zyrln
  6. Permissions رو دست نزن. باید این ۵ تا باشن:
    • ✅ Account → Workers Scripts → Edit
    • ✅ Account → Workers KV Storage → Edit
    • ✅ Account → Workers Routes → Edit
    • ✅ Account → Account Settings → Read
    • ✅ User → User Details → Read
  7. Account Resources: Include → All accounts
  8. Client IP Filtering: خالی بذار
  9. TTL: خالی بذار (همیشه فعال)
  10. روی Continue to summary → Create Token
  11. ⚠️ توکن رو فوراً کپی کن! فقط یک‌بار نشون داده می‌شه.
🔒 امنیت: توکن فقط برای ساخت Worker استفاده می‌شه. بعد از ساخت می‌تونی از همون صفحه پاکش کنی.
۳ پیدا کردن Account ID ۱ دقیقه
  1. برو به dash.cloudflare.com
  2. در صفحه اصلی، سمت راست، یه باکس به اسم Account ID داری
  3. روی دکمه کپی (📋) کنارش بزن
